# 🧮 A EQUAÇÃO DO FUTURO: Equalização de ROF (ROFE) v10.3

O **Return on Future (ROF)** não é um número estático; ele é o resultado de uma **Equalização Dinâmica** entre três forças fundamentais do sistema Futurama.

---

## 🏗️ A Fórmula de Equalização

O ROF é calculado através da interação recursiva entre:
$$ROF = (Alpha \times Momentum) \times \text{Brand Elasticity} \times \text{Strategic Alignment (Aaker)}$$

### 1. O Input Bruto: Sinais & Alpha ($\alpha$)
Diferente do ROI que olha para o faturamento real, o ROF olha para o **Alpha Cultural**.
- **Sinais Captados (Volume & Tensão):** Definem o tamanho da oportunidade. Se captamos sinais de "E-Sports Regional" com alta tensão em BA, o Alpha potencial aumenta.
- **Alpha ($\alpha$):** É a medida de "tração extra" que a marca ganha ao se alinhar a esses sinais. Se a marca ignora os sinais, seu Alpha é 1.0 (neutro). Se ela os absorve, o Alpha sobe para 1.25+.

### 2. O Modificador de Ganho: Onboarding & Objetivos
Aqui entra a "Vontade do Usuário". O sistema equaliza o ROF dependendo do que você definiu no Onboarding:
- **Objetivo: Lançamento de Produto** -> O sistema dá peso 0.9 para **Awareness**. O ROF sobe rápido com qualquer ganho de Alpha, pois o foco é "ser visto".
- **Objetivo: Proteção de Marca** -> O sistema dá peso 0.9 para **Loyalty**. Aqui, mesmo um Alpha alto pode gerar um ROF baixo se os sinais captados indicarem rejeição das personas sintéticas (Crivo das Almas).

### 3. O Filtro de Realidade: Brand Equity & Elasticity
A **Elasticidade de Marca** (SP/RJ/BA/MG) funciona como o limite físico dessa expansão:
- **Elasticidade Alta (BA - 95%):** A marca consegue converter 100% do seu Alpha em "Valor de Opção de Futuro". O ROF explode.
- **Elasticidade Baixa (MG - 55%):** Existe uma "perda de carga". A marca precisa de muito mais Alpha para mover o ponteiro do ROF, pois a fricção cultural com a tradição é maior.

---

## 🔄 Exemplo de Equalização em Tempo Real (Dashboard)

1. **Sinal Captado:** *Hackerismo de Quebrada* (Tensão: Alta).
2. **Ação do Usuário:** "Lançar campanha focada em Gambiarra Tech".
3. **Ganho de Alpha:** +25% (O sistema detecta que a ação ressoa com o sinal).
4. **Equalização (ROFE):**
   - Se o estado for **SP**, o ROF sobe moderadamente (Elasticidade 65%).
   - Se o estado for **BA**, o ROF sobe drasticamente (Elasticidade 95% + Resonância com Persona Enzo).
   - O resultado final no Dashboard é o **ROF Score**, que diz ao Board: *"Esta ação de hoje garantiu X% de dominância cultural nos próximos 6 meses nesse estado."*
